# DetailedCoolingMotor

OBJ meshes generated for the Dubai Motor Re-X MVP.

Source reference: `external_models/sources/OpenMotor-Hardware`, which keeps the downloaded OpenMotor STEP CAD files under CERN-OHL-W-2.0. These runtime meshes are separated into the exact MVP component IDs so Unity, Gazebo, the task planner, and the dashboard can swap in CAD-derived parts later without API changes.
